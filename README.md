**EmployeeHub v2**
Integrated Human Resource Information System (HRIS) Dashboard. This integrated Human Resource Information System (HRIS) dashboard is designed to transform manual HR administrative workflows into a centralized and efficient digital operational system.

**What the Project Does**
This project digitalizes core HR operational activities, including employee data management, attendance tracking, payroll calculation, and operational analytics reporting. The system replaces manual spreadsheet-based administration with an automated real-time dashboard workflow to improve operational accuracy and efficiency. EmployeeHub v2 integrates attendance synchronization, payroll automation, and HR analytics into one connected frontend system using Vanilla JavaScript architecture.

**Why the Project is Useful**
1. Real-Time Synchronization = Automatically updates payroll calculations and dashboard analytics whenever attendance data changes.
2. Payroll Automation = Calculates employee salaries based on attendance records, attendance bonuses, and absence deductions automatically.
3.Operational Efficiency = Reduces repetitive HR administrative work such as attendance recaps, payroll calculations, and reporting processes.
4. Dashboard Analytics = Provides operational insights related to employee attendance, payroll expenditure, and absence monitoring through an interactive dashboard.
5. Frontend System Integration = Integrates HTML, CSS, and Vanilla JavaScript logic into a single responsive HR operational workflow system.

**How Users Can Get Started**
To run this project in a local environment, follow these steps:
1. Ensure your device has a modern web browser installed.
2. Open the project folder using Visual Studio Code.
3. Run the index.html file directly or use the Live Server extension.
4. The EmployeeHub v2 dashboard system will automatically run in the browser.
This project currently uses a frontend-only architecture without backend or database integration. Future development may include database systems, authentication features, and cloud deployment integration.
